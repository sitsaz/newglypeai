========================================================================
راهنمای استقرار و استفاده از اسکریپت نوین NewGlype روی هاست اشتراکی رایگان PHP
========================================================================

این پکیج به صورت ۱۰۰٪ خودکفا (Standalone) و بدون نیاز به نصب هیچ‌گونه ابزار جانبی یا Composer طراحی شده است.
تنها با استخراج این فایل‌ها روی هاست خود، سیستم به صورت خودکار شروع به کار خواهد کرد.

------------------------------------------------------------------------
مراحل نصب روی هاست (cPanel / DirectAdmin / File Manager):
------------------------------------------------------------------------

۱. وارد پنل مدیریت هاست خود (cPanel، دایرکت ادمین یا پنل هاست رایگان) شوید.
۲. به بخش «File Manager» (مدیریت فایل) و سپس پوشه «public_html» (یا پوشه ریشه سایت) بروید.
۳. فایل zip دانلود شده (newglype-php-host.zip) را آپلود کنید.
۴. روی فایل راست کلیک کرده و دکمه «Extract» (استخراج) را بزنید تا تمام فایل‌ها در همان مسیر باز شوند:
   - index.php
   - proxy.php
   - .htaccess
   - includes/
       -- CookieJar.php
       -- ProxyEngine.php
       -- proxyHook.js
۵. آدرس دامنه هاست خود (مثلاً https://yoursite.com یا آدرس ساب‌دامین رایگان) را در مرورگر باز کنید.
۶. کار تمام است! سیستم فوراً آماده استفاده است.

------------------------------------------------------------------------
ویژگی‌های بهینه‌سازی شده در این نسخه نوین:
------------------------------------------------------------------------
✓ حل مشکل دکمه‌های وبسایت‌های مدرن (مانند لاگین گوگل و SPAs) با تزریق هوشمند قلاب جاوااسکریپت کلاینت
✓ مدیریت کوکی‌ها مطابق با استاندارد RFC 6265 و پشتیبانی از Subdomain ها
✓ همگام‌سازی لحظه‌ای کوکی‌های جاوااسکریپت (document.cookie) با سشن سرور
✓ پشتیبانی همزمان از cURL و fallback با stream context در صورتی که cURL در هاست رایگان محدود باشد
✓ حذف هدرهای محدودکننده فریم (CSP & X-Frame-Options)
✓ سازگار با کلیه نسخه‌های PHP از نسخه 7.2 تا 8.3
