# Glype Web Proxy - Community Maintenance Fork (Personal Use)

## Project Description

This repository hosts a community-maintained fork of the classic **Glype** web-based proxy script. It is primarily intended for **personal use** and to contribute to the **community maintenance effort** by addressing bugs and improving compatibility based on the original Glype codebase.

Glype is a free, web-based proxy written in **PHP** that allows users to easily browse the internet anonymously and access websites that may be blocked or restricted by network filters.

## Purpose

This fork serves as a **personal repository** for maintaining and updating the original Glype codebase. While primarily maintained for personal use, the aim is to keep the code functional and compatible with modern environments. Contributions focused on bug fixes and compatibility improvements are welcome as part of a broader community effort to keep Glype usable.

## Features

- **Web-based Interface:** Accessible from any modern web browser.
- **Anonymous Browse:** Masks the user's IP address from target websites.
- **Unblock Websites:** Can be used to bypass geo-restrictions and access content blocked by local networks.
- **Self-Hostable:** Easy to deploy on your own web server with PHP support.
- Based on the classic, well-known Glype proxy script.

## Installation

To get a copy of this Glype maintenance fork up and running on your web server:

1.  **Clone the repository:**

    ```bash
    git clone [https://github.com/NamBZ/glype.git](https://github.com/NamBZ/glype.git)
    ```

    Alternatively, you can download the source code as a ZIP file from the repository page.

2.  **Upload to your web server:** Upload the contents of the cloned repository to a directory accessible by your web server (e.g., `public_html` or a subdirectory within it).
3.  **Ensure PHP is installed and configured:** Make sure your web server environment has PHP installed and enabled. This fork aims to be compatible with recent PHP versions (e.g., PHP 7.4+ or PHP 8.x - confirm based on your testing).
4.  **Configuration (Optional but Recommended):** Review and edit the configuration files within the `include/` directory if you need to customize settings, themes, or access controls. Refer to the original Glype documentation for details on configuration options.
5.  **Access via browser:** Open your web browser and navigate to the URL where you uploaded the Glype files on your server.

_(Note: Specific permissions for directories/files might be required depending on your server setup. Consult your hosting documentation if you encounter permission errors.)_

## Usage

Simply access the Glype proxy URL in your web browser. Enter the address of the website you wish to visit in the input box provided on the main page and click the submit button.
