افزونه وب پروکسی نوین NewGlype برای وردپرس با پشتیبانی از وبسایت‌های مدرن، کوکی جار RFC 6265 و برگه اختصاصی در سایت.

== Description ==

افزونه **NewGlype Web Proxy** وبسایت وردپرسی شما را به یک پروکسی وب تمام عیار و مدرن تبدیل می‌کند.

ویژگی‌های کلیدی:
* **ایجاد برگه اختصاصی خودکار:** به محض فعال‌سازی، برگه جدیدی با نام «وب پروکسی NewGlype» در آدرس `/web-proxy/` در سایت شما ساخته می‌شود.
* **شورت‌کد انعطاف‌پذیر:** می‌توانید با قرار دادن شورت‌کد `[newglype_proxy]` در هر برگه یا نوشته دلخواه، فرم پروکسی را نمایش دهید.
* **حل مشکل دکمه‌های سایت‌های مدرن (مانند لاگین گوگل):** با تزریق خودکار قلاب جاوااسکریپت، توابع `fetch` و `XHR` بازنویسی می‌شوند.
* **مدیریت کوکی RFC 6265:** پشتیبانی از ساب‌دامین‌ها و همگام‌سازی لحظه‌ای کوکی‌های مرورگر با سشن سرور.
* **حذف هدرهای مسدودکننده:** حذف خودکار `X-Frame-Options` و `Content-Security-Policy`.
* **سپر ضد SSRF:** جلوگیری از اسکن پورت‌ها یا دسترسی به آدرس‌های لوکال سرور.

== Installation ==

۱. وارد پنل مدیریت وردپرس (پیشخوان) شوید.
۲. به بخش **افزونه‌ها > افزودن افزونه** بروید.
۳. دکمه **بارگذاری افزونه** را زده و فایل زیپ `newglype-proxy.zip` را انتخاب کنید.
۴. روی **نصب** و سپس **فعال‌سازی** کلیک کنید.
۵. برگه اختصاصی پروکسی در مسیر `yoursite.com/web-proxy/` بلافاصله آماده استفاده است!
